# 음성 기반 소부대 오프라인 전술 C2 체계

> 상급 망이 끊긴 상황에서도 분대·소대가 휴대 단말과 저전력 무선만으로 위치·표적·보고를 공유하고, 온디바이스 AI가 이를 공통상황도(COP)와 자연어 브리핑으로 정리하는 소부대 전술 C2 시제품

**Deploy for Defense 2026 · Team 노안** | 트랙: T4-01 소부대 오프라인 전술 C2·COP × T4-02 핸즈프리 음성 온디바이스 전술 AI

---

## 1. 목적

대대급 이상 지휘통제체계는 고도화되었지만, 실제 교전이 벌어지는 분대·소대는 여전히 육성·무전·종이 지도·개인 기억에 의존합니다. 본 프로젝트의 목적은 다음 세 가지입니다.

- **상급 망 비의존**: 대대 C2망 두절·전파 방출 통제(EMCON) 상황에서도 소부대 단독으로 COP 유지
- **핸즈프리 입력**: 손은 장비, 눈은 전방인 병사가 말하지 않고 또는 짧은 발화만으로 보고
- **온디바이스 AI**: 외부망 없이 단말·노트북 내부에서 보고 구조화·상황 요약·교범 질의 처리

## 2. 해결하고자 하는 문제

| 문제 | 현행 | 영향 |
|---|---|---|
| 육성·무전 의존 | 구두 보고·지시 | 소리·전파로 위치 노출, 오청취, 기록 부재 |
| 표적 위치 공유 한계 | 발견자 기준 방향·수신호 | 수신자가 자기 기준 위치를 암산 |
| 전투 데이터 부재 | 기억·사후 보고 | 부정확, 축적 불가 |
| 교범 접근성 | 종이 교범 | 교전 중 열람 불가 |
| 상급 망 단절 | 대대 C2망 의존 | 소부대 COP·전황 공유 동시 상실 |

## 3. 해결 방안

| 문제 | 해결 | 단계 |
|---|---|---|
| 육성·무전 의존 | 조이스틱·버튼 무음 보고, 음성 → 표준 양식 자동 구조화, 송수신 자동 기록 | 부분 구현 |
| 표적 위치 공유 | 발견자 위치·방위·거리로 표적 좌표 계산 → 병사마다 자기 기준 방향·거리로 음성 안내 | 구현 |
| 전투 데이터 | 위치·보고·명령·결심 시간순 자동 기록 | 부분 구현 |
| 교범 접근성 | 음성 질의 → 단말 내 교범 검색 → 근거 조항 포함 답변 | 설계 |
| 상급 망 단절 | BLE 기반 분대 내 통신 + 앵커리스 상대측위 + 오프라인 COP | 구현 |

## 4. 시스템 구성

```
[병사 NU40-DK ×N] ──BLE──▶ [분대장 Arduino UNO Q] ──Wi-Fi(시연)──▶ [소대장 노트북 COP]
 조이스틱·버튼 보고          상대측위(MDS)·위치표 하향            지도 COP·보고 승인
 이어폰 음성 수신            명령 하달(버튼·음성)                로컬 LLM 브리핑·명령 하달
        ◀──────────── 명령·위치표·공유 보고·수신 확인 ─────────────┘
```

- 병사–분대장: BLE 연결(NUS) 및 광고. 분대장–소대장 구간은 시연용 Wi-Fi로 대체하며, 실전에서는 전술 데이터 무전을 상정
- 중대·대대 체계는 범위 외

## 5. 핵심 기능

**① 병사 무음 보고** — "조이스틱 = 방향·거리, 버튼 = 내용". 기울이고 누르는 최대 2동작으로 적 발견(인원수), 의심 징후, 부상자, 폭발물 의심, 수신 확인 등을 보고합니다. 적 발견 보고 1건은 **13 B**로, 같은 내용의 음성 3초(약 12 KB) 대비 약 1/900 수준입니다.

**② 표적 위치 공유** — 무선 구간은 절대 방위로 전송하고, 수신 측이 자기 위치·방위 기준으로 변환해 "적 3, 2시, 근거리"처럼 이어폰으로 안내합니다. 같은 표적이 병사마다 다른 시계 방향으로 들립니다.

**③ 음성 보고 구조화** — 분대장의 발화를 SALUTE·MEDEVAC 등 표준 양식 JSON으로 변환하고, 누락 항목은 되묻습니다.

```json
{ "type": "SALUTE", "sender": "1-1", "conf": 0.88,
  "fields": { "size": 3, "activity": "능선 따라 남하",
              "location": { "bearing": 87, "dist": 150 }, "equipment": "소총" } }
```

**④ 앵커리스 상대측위** — 병사 간 BLE RSSI → 경로손실 모델 → 거리행렬 → 고전 MDS로 분대 대형을 복원합니다. GPS 재밍·음영 환경, GPS 미탑재 태그에서도 대형 이탈·고립 인원을 식별합니다.

**⑤ 전파 방출 통제(EMCON)** — 침묵(병사 송신 0, 분대장 광고 수신만), 최소(송신 출력 −40 dBm, 긴급 보고만 즉시), 정상의 3단계 모드를 지원합니다.

**⑥ COP 대시보드와 Human-in-the-Loop** — MIL-STD-2525 부호 지도에 아군·표적·링크를 표시합니다. AI 신뢰도 0.7 미만 보고는 소대장 승인 대기로 두고, 승인·수정·재확인·기각 이력을 기록합니다.

**⑦ 명령 하달·수신 확인** — COP → 분대장 → 병사로 명령을 전달하고 병사 버튼 확인을 인원별로 집계합니다. 미수신자에게는 8초 간격으로 최대 3회 재전송하고, 통신 복구 시 저장 후 전달합니다.

**⑧ 로컬 LLM 브리핑** — 서버가 방위·거리 등 사실을 계산하고 LLM은 문장화만 담당해 환각을 줄입니다. LLM이 없으면 규칙 기반으로 대체합니다.

## 6. 기술 스택

| 계층 | 기술 |
|---|---|
| 병사 단말 | Nucode NU40-DK (nRF52840), Arduino C++, Adafruit Bluefruit, BLE NUS, IMA ADPCM 8 kHz, CRC-16 |
| 분대장 단말 | Arduino UNO Q (Linux + MCU), Python, Bleak(BLE Central), 고전 MDS 측위, SoftAP TCP |
| COP 서버 | Python FastAPI (REST·WebSocket·SSE), HTTP/UDP/Serial NDJSON 수집 |
| COP 화면 | React, TypeScript, Vite, Zustand, Tailwind CSS, react-leaflet, milsymbol, MGRS, 오프라인 지도 타일 |
| 온디바이스 AI | Ollama 로컬 LLM (EXAONE 3.5 / Qwen 계열), whisper.cpp STT(설계) |

## 7. 구현 현황과 한계

- **구현**: 병사 단말 보고·명령 수신·EMCON, 분대장 BLE 중계·상대측위, COP 대시보드, 보고 승인, 명령 하달·재전송, 로컬 LLM 브리핑
- **설계**: 분대장 보드 STT 이식, 교범 RAG, 저장 데이터 암호화·탈취 시 소각
- **한계**: RSSI 거리 추정 오차가 커 개별 좌표보다 대형 판단 용도에 적합(정밀 측위는 UWB 확장 검토), 현재 프레임은 CRC·중복 제거만 적용되어 암호화·인증 추가 필요

## 8. 군 적용 가능성

- **저비용·신속 전력화**: 상용 부품(COTS) 기반, 핵심 기능은 소프트웨어
- **망 두절 시 지속 운용**: 상급망 단절·EMCON 상황에서도 분대 단독 작동
- **병력 감소 대응**: 1인당 정보 처리 부담 증가를 보고·요약 자동화로 보완
- **훈련 단계 우선 적용**: 교육훈련 사후검토(AAR)부터 적용해 전투 데이터 축적
